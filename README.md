# GameSense — From Random Flaps to Intelligent Flight 🎮

**WiDS 6.0 | Collaborative Project | IIT Bombay | 6 weeks | Beginner-friendly**

## 🗺️ Our project progression

| Week | Learn | Build for the final project | One small check-in |
| --- | --- | --- | --- |
| **1 — Start here** | Python refresh, RL concepts, Gymnasium | Run random Flappy Bird policy; collect CSV + graph | Label the RL loop |
| 2 | Q-Learning, exploration, Bellman update | Hand-written rule-based baseline and fair evaluator | One Q-value update |
| 3 | PyTorch and DQN | Q-network, replay buffer, initial update | Forward-pass check |
| 4 | Training stability | Train, checkpoint and plot learning curves | Interpret one graph |
| 5 | Model evaluation | Compare a controlled change to baseline | Explain one result |
| 6 | Integration | AI playback demo, benchmarks and report | 3-bullet reflection |

**One shared project, not six disconnected assignments.** Plan for ~8 hours/week of learning, collaborative coding and discussion. Individual weekly checks take just 10–15 minutes.

## 🎯 Final outcome

- Working Flappy Bird environment and random / heuristic / trained DQN agents
- Reproducible PyTorch training, saved model checkpoints and evaluation
- Experiment graphs comparing measured performance (no invented improvement claims)
- AI playback demo, technical report and documented GitHub repository

**Stretch goals only after the core works:** Double DQN, changed pipe gaps, a polished dashboard or a human-play mode.
